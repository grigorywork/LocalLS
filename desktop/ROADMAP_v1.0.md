# LocalLS Desktop — основа v1.0

Рабочая ветка 0.1.0 остаётся отдельным клиентом SSH/SFTP. Android LocalLS и текущий
автозапуск серверного sshd сохраняются.

Следующие этапы после проверки установщика на Windows 10 и 11:

1. Несколько серверных профилей с независимыми секретами и доверенными ключами.
2. Рекурсивные передачи папок с предварительным просмотром, отменой и понятными конфликтами.
3. Вход по SSH-ключу, возобновление передач и пакетные действия.
4. Проверка Windows DPAPI, установки/удаления, трея и реального Tailscale на Windows.
5. Подписанная сборка и воспроизводимая CI-сборка на Windows.
6. Опциональная роль сервера на ПК — отдельный проектный этап; без добавления
   конкурирующих способов запуска SSH на Android.

Протокол публичного профиля localls-server-v1, изоляция renderer, проверка
SSH-ключей и независимый агент управления остаются базой следующей версии.
