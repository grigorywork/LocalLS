## Реализовано

- Интерфейс для Windows: левое меню, две файловые панели, компактные кнопки с
  иконками, отдельная правая шторка настроек, пять цветовых тем и формы кнопок.
- SSH с подтверждением первого ключа до парольного входа; изменённый ключ блокирует
  аутентификацию. Импорт/экспорт публичных профилей Android localls-server-v1.
- SFTP: папки, отправка вложений, выбор файлов в разных папках, скачивание в любую
  папку Windows, очередь, отмена, история и график измеренной скорости за 60 секунд.
- Закрытие и сворачивание оставляют приложение в трее; активные передачи продолжаются.
- Пароли и токены сохраняются только при включённой опции системного шифрования;
  при его недоступности остаются в памяти. Публичные профили не содержат секретов.
- Tailscale в отдельном меню: реальный статус установленного клиента, up/down,
  отдельный VPN-IP / MagicDNS и выбор Local/VPN для следующего подключения.
- Управление существующим серверным агентом: статус, запуск, остановка и перезапуск
  SSH-службы. Сервер, автозапуск sshd и Android-проекты не изменялись.

## Найденные и исправленные ошибки

1. Сетевые ограничения среды и загрузка Electron через fetch без прокси: использован
   штатный прокси среды; последняя сборка использует уже скачанный официальный ZIP.
   SHA-256 ZIP сверялся с checksums.json закреплённой версии Electron.
2. Отсутствовал конвертер rsvg-convert: PNG и многоразмерный ICO создаются через
   Resvg и корректный ICO-контейнер, без зависимости от внешнего конвертера.
3. При быстрой передаче очередь не успевала сообщить состояние running: добавлено
   немедленное обновление. График учитывает реальную разницу байтов за интервал,
   включая короткие передачи.
4. Папка Downloads могла отсутствовать: добавлен безопасный начальный путь.
5. Сохранение другого адреса/пользователя могло оставить старое соединение и выбор:
   соединение сбрасывается; ответы прежних запросов не заменяют актуальную панель.
   Секреты разделяются по адресу, порту и пользователю.
6. Статус агента читался из неверного поля: используется реальное поле sshd протокола
   существующего сервера, без изменения серверных файлов.
7. Стандартный этап создания деинсталлятора требовал Wine; загруженный комплект Wine
   также не запускался. Итоговый NSIS-скрипт компилирует установщик и деинсталлятор
   непосредственно, без запуска Wine.
8. Завершающая обработка публикации electron-builder падала на channel=null:
   публикация отключена (publish: [], --publish never).
9. Исправлены кавычки генерируемого списка удаления. Деинсталлятор удаляет только
   файлы приложения по списку; произвольные файлы и пользовательские настройки сохраняются.
10. В первоначальную Windows-упаковку попадали необязательные Linux .node-файлы:
    исключены нативные дополнения cpu-features/nan/sshcrypto. Переносимый SSH/SFTP
    отдельно проверен с отключённой загрузкой всех .node-дополнений.
11. Устранены две ошибки самого UI-теста: вычисление пути в неподходящем контексте
    Electron и недостаточный таймаут реальной фоновой передачи. Приложение проверялось
    повторно; успешные результаты сохранены отдельно.

## Границы проверки

Физической Windows 10/11 в этой среде нет: установка/удаление и запуск именно под
Windows не выполнялись. Linux UI-тест не выдаётся за Windows-тест. Также не
проверены настоящий вход в аккаунт Tailscale, Windows DPAPI и управление агентом
на пользовательском телефоне. Для этих операций нужны соответствующая ОС,
установленный клиент/аккаунт и доступ к серверу с его секретами.

Версия 0.1.0 передаёт обычные выбранные файлы. Рекурсивная передача папок,
создание сервера на ПК и управление питанием телефона не входят в этот этап.
Перезапуск означает перезапуск SSH-службы через уже существующий агент.
