# LocalLS Desktop 0.1.0

Windows 10/11 x64 SSH/SFTP client, developed separately from Android LocalLS 0.9.3.
Client stage: connects to the existing Termux/OpenSSH server; no new server installation.

Windows interface: side navigation, two file panes, compact actions, transfer queue and
speed graph, public profile import from Android, connection/appearance/VPN settings, tray.

Typical public connection parameters: 192.168.1.82, port 8022, user u0_a606.
Credentials are entered in the app and never included in this project.

Установщик: `artifacts/LocalLS-0.1.0-Windows-x64-Setup.exe`.
Результаты реальной сборки и проверки: `BUILD_REPORT.md`.

Приложение работает на Windows 10/11 x64. Установите его для текущего пользователя,
откройте «Подключение», введите адрес, SSH-порт, пользователя и пароль, сохраните
параметры и подключитесь. При первом подключении сверьте отпечаток SSH-ключа.
Импорт JSON-профиля из Android поддерживается; секреты в профиль не включаются.

На экране «Файлы» двойной щелчок открывает папку. Выберите файлы на сервере,
переходите между папками и нажмите «Скачать выбранное»: приложение предложит
выбрать любую папку Windows. Существующие локальные файлы сохраняются: новые
получают свободное имя. Для отправки выберите локальные файлы либо прикрепите
их через кнопку «Отправить». Очередь потоковая, с отменой и историей. График
показывает измеренную скорость за последние 60 секунд.

Крестик окна и сворачивание оставляют приложение в системном трее вместе с
передачами. Для завершения откройте меню значка LocalLS → «Выйти».
Цвета и формы кнопок меняются в «Настройках». Tailscale вынесен отдельно: нужен
установленный официальный клиент и выполненный вход. VPN-IP / MagicDNS сервера
задаётся в этом разделе. Приложение использует клиент Tailscale, а не собственный VPN.

«Управление сервером» использует существующий HTTP-агент Android LocalLS на
отдельном порту, обычно 8787. Сохраните токен и порт, затем используйте запуск,
остановку, перезапуск SSH и статус. Эти команды не выключают телефон и не меняют
схему автозапуска. Для этой версии сервер уже должен быть настроен.

Пароли и токены остаются в памяти, пока вы не включите сохранение в системном
защищённом хранилище Windows. При недоступности системного шифрования опция
отключается. Профили, история и доверенные ключи хранятся в пользовательских
данных LocalLS. Для удаления программы завершите её через трей и воспользуйтесь
«Установленными приложениями» Windows. Пользовательские настройки сохраняются.

Первая версия передаёт выбранные обычные файлы; рекурсивная передача папок,
редактор удалённых файлов и создание сервера на ПК в неё не входят.

```sh
npm ci
npm test
npm run test:ui
npm run build:win
node tools/verify-package.cjs
```

Для Linux UI-проверки нужен X-сервер; тестовый запуск Electron использует
`--no-sandbox` только внутри тестового инструмента. Windows-приложение запускает
изолированный renderer с `sandbox: true`, без Node и с CSP. Сборка Linux не выдаётся
за тест на Windows. NSIS собирает подлинный установщик со встроенным деинсталлятором
из Windows-файлов Electron; Wine для итоговой сборки не требуется.
