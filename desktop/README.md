# LocalLS Windows 1.35 — MSS9LN

Клиент и сервер SSH/SFTP для Windows 10/11 x64.

## Подключиться к телефону

1. Подключи устройства к одному Wi-Fi.
2. Покажи QR-код на телефоне. На ПК открой «Подключение → Открыть QR-код» и выбери PNG или фото.
3. Выбери изображение QR-кода, сверь код и разреши доступ на телефоне.
4. Открой «Файлы» и выбери направление передачи. Прогресс, время и повтор — в «Очереди».

## Использовать ПК как сервер

1. В «Настройках → Сервер компьютера» выбери папку доступа.
2. На вкладке «Сервер» нажми «Включить». Разреши доступ в частной сети, если спросит брандмауэр Windows.
3. Покажи QR-код, подключись с телефона и подтверди запрос на ПК.

Доступ только по ключу, до семи устройств. Отзыв доступа — в списке устройств. Ключи хранятся через защищённое хранилище Windows. Крестик оставляет приложение в трее; завершение — через «Выйти» в меню трея.

Темы, светлый фон, стекло и светлая обводка — в «Настройках».

Переключатели оформления сохраняются сразу. Системное матовое стекло поддерживается в Windows 11 22H2+; на остальных версиях используются матовые панели.
