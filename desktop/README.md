# LocalLS Windows 1.43 — MSS9LN

Клиент и встроенный SSH/SFTP-сервер для Windows 10/11 x64.

1. На сервере выбери папку, включи LocalLS и покажи QR-код.
2. На втором устройстве считай QR-код или открой PNG/фото. Сверь код и подтверди доступ.
3. Передавай файлы в «Файлах». В «Очереди» — время, отмена всего списка, очистка и повтор.

До 10 разрешённых устройств. Входящие попадают в папку, указанную на вкладке «Сервер». Локальные папки доступны с разрешениями текущего пользователя. Крестик оставляет сервер в трее; «Выйти» завершает его. Во время работы сервера LocalLS блокирует автоматический сон, но не выключение экрана. Ручной сон/гибернация прерывает сеть.

Язык, цвет, светлый фон и стекло — отдельные настройки. Системное матовое стекло требует Windows 11 22H2+; иначе используются матовые панели внутри окна. Ключи хранятся в защищённом хранилище Windows. Установщик пока без подписи издателя.

English: Choose a server folder, start the server, show its QR code and approve the client. Files supports local folder selection, preview and transfer; Queue supports ETA, cancel all, clear and retry. Uploads go to the displayed server folder. Closing the window keeps LocalLS in the tray; Quit stops it. Automatic idle sleep is inhibited while hosting, but manual suspend interrupts networking. Up to 10 devices. Language, accent, light background and glass are independent settings. The installer is currently unsigned.
