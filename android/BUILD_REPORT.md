## Изменения и исправления

1. Убраны оба крестика и «Свернуть» из главной правой шторки. Закрытие — scrim и системный Back.
   Сворачивание в уведомление сохранено в проводнике; Home сохраняет обычную работу в фоне.
2. Шторка шириной 50%: отдельные разделы подключения, настроек, Wi-Fi, оформления, инструментов
   и VPN/Tailscale. Открыт только один раздел; стрелка показывает состояние.
3. Кнопки Dashboard 52 dp с иконкой сверху и подписью; строки меню 48 dp с иконкой слева.
   Цветовые темы и облако с молнией сохранены. Формы значков функций сохраняются: без рамки,
   круг, скруглённый квадрат, квадрат. Контур полупрозрачный чёрный. Маска launcher зависит от Android.
4. Отдельная кнопка «Перезапуск SSH» вызывает подтверждённый POST /restart независимого агента.
   Телефон не перезагружается. Без токена открываются параметры агента; команда через ту же SSH-сессию не отправляется.
5. VPN, адрес, маршрут, fallback и мастер собраны в VPN-разделах. Нет дублирования fallback в общих настройках.
6. Keystore вынесен в общий последовательный фоновый поток; сеть — в независимые cancellable задачи.
   Проверки не обновляют чужой профиль после смены адреса/экрана. На скрытом Dashboard автопроверка остановлена.
   Старые зелёные показатели сбрасываются при смене профиля. Несохранённый IP не теряется при возврате.
7. Неизменившиеся графики/подписи не перерисовываются каждые 500 мс.
8. «Этот телефон — сервер»: мастер сразу подготавливает существующую среду, когда Termux/SAF/RUN_COMMAND готовы.
   Первый запуск требует штатных разрешений Android. Пароль не заменяется автоматически;
   удалённый профиль и единственная схема запуска sshd сохраняются.
9. Wi-Fi на текущем серверном телефоне: SSID/WPA2 или открытая сеть, системные настройки, фактический IPv4.
   Android 11+: явный доверенный системный обработчик добавления сети; Android 10: сетевая рекомендация
   с разрешением Android; Android 7–9: системные настройки. Команда не считается фактическим подключением.
10. Исправлена найденная javac-ошибка: FilesActivity использует runOnUiThread для завершения фонового чтения.
    Исправлена lint-ошибка CoarseFineLocation: Wi-Fi-рекомендация используется только на API 29;
    fine/coarse permissions ограничены этой версией. Повторные clean build + lint завершились успешно.
11. Проверка расположения иконок в popup обновлена под компактные строки и плитки. После первого
    полного прогона единственная test failure устранена; окончательный полный прогон выполнен заново.
