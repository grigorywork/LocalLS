# LocalLS Android 0.11.11 — компактное отображение IP

LocalLS Android 0.11.11 — компактный IP Wi-Fi.

По просьбе владельца «Текущий IP Wi-Fi» и адрес теперь показаны одной обычной строкой размером 14sp. Убраны крупный заголовок, жирные цифры, цветная рамка, отдельное пояснение и кнопка «Скопировать IP». При отсутствии адреса строка кратко сообщает «нет адреса». Несколько адресов перечисляются через запятую; при крупном системном шрифте строка переносится.

IP продолжает обновляться при смене Wi-Fi, пока экран открыт, и при возвращении. Пункт остаётся на главном экране в «Мой сервер» и в настройках собственного сервера. На другом телефоне вводи адрес телефона-сервера в существующем подключении.

Авторизация по ключу, проверка fingerprint, параметры подключения и исправление хранения разных клиентских ключей из 0.11.10 не менялись. Постоянная release-подпись прежняя, versionCode 31 > 30. Установи поверх 0.11.10 без удаления приложения и очистки данных, после обновления включи сервер вручную.

[Инструкция](https://github.com/grigorywork/LocalLS/blob/android-v0.11.11/android/app/src/main/assets/phone-setup.txt) обновлена и встроена в APK.

115 JVM-тестов и 7 Python-тестов прошли без ошибок и пропусков, lint без ошибок. Макеты проверены с масштабом шрифта 1 / 1.5 / 2. Физический телефон не подключён, установка на устройство не выполнялась.

Изменена только подача IP и сопутствующие ресурсы/документация. WifiAddressView состоит из одной TextView: подпись и адрес обычным шрифтом 14sp без принудительного выделения, цветной рамки, подсказки и кнопки. Методы копирования в clipboard, диалог выбора адреса, связанные строки/ID удалены. При нескольких адресах показывается полный список через запятую с естественным переносом. Текущее определение адреса и экранный таймер сохранены. Строка не является интерактивной кнопкой.

Тесты прежнего копирования удалены вместе с функцией. Существующие сценарии адаптированы к компактной строке: собственный адрес отдельно от удалённого профиля, смена сети и удаление старого адреса, исключение VPN/Cellular и список нескольких адресов. Новых тестов, повторяющих простую вёрстку, не добавлено. Общие проверки подписей кнопок и макетов выполняются на всех темах при масштабе 1 / 1.5 / 2; предпросмотры проверены вручную.

SshKeys, HostTrustStore, SFTP и серверная политика в этой ревизии не менялись. Ключи, настройки, выбранные папки и файлы не сбрасываются. Сетевые ограничения и ограничения фоновой работы из предыдущих отчётов сохраняются; реальные Wi-Fi и поведение конкретного производителя не проверены без телефона.
