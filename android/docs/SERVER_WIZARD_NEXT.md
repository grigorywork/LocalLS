# Продолжение Android-мастера после 0.9.5

Основа: main / 45482d1, grigorywork/LocalLS. Ветка: codex/android-server-wizard-readiness.
Задачи: [мастер #2](https://github.com/grigorywork/LocalLS/issues/2),
[безопасность #3](https://github.com/grigorywork/LocalLS/issues/3).

## Реализовано

- Семь шагов мастера с проверкой реального SAF-доступа и RUN_COMMAND.
- Подтверждение SSH/экспорта связано с актуальной подготовкой, портом и пользователем.
- Отдельный ключ мастера хранится зашифрованным и используется повторно.
  Новый вход допускает только publickey; парольный резервный доступ сохраняется.
- Существующий HTTPS-агент проверяется по сертификату из Termux HOME до токена.
- Новая кнопка готовит HTTPS-агент на телефоне через проверенный локальный SSH.
  Сохраняет существующие token/cert/config и работающие процессы, защищает от
  дубликатов и параллельной установки. Остановленный агент обновляется атомарно.
- Работающий sshd, его host keys/config и boot-схема сохраняются.
- Подтверждение успеха требует фактического HTTPS-статуса после установки.

Результаты и границы: [отчёт](SERVER_WIZARD_BUILD_REPORT.md).
