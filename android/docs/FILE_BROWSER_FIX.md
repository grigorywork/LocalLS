# Проверка файлового браузера после разбора записи

Источник симптомов — переданный пользователем текстовый разбор; само видео в этой сессии не получено.
Успешная авторизация SSH не доказывает доступность Termux storage/shared.

## Изменения

- При ошибке открытия папки очищается прежний список, причина остаётся на экране.
- В диалоге выбора пути доступна «Домашняя папка»: SFTP разрешает `.` в фактический
  абсолютный путь, который используется для отображения, сохранения и загрузки файлов.
- Ошибки отсутствующего пути/доступа не вызывают переключение на резервный сервер.
- Отправка и создание папок требуют успешно открытого каталога; изменение каталога
  после подтверждения отправки требует повторного подтверждения.
- Статус доступного порта поясняет, что авторизация не выполнена.
- Кнопка сохранения подключения планирует проверку через 750 мс; смена профиля или
  уход с экрана отменяет её. Проверка fingerprint сохраняется.
- Пароль перенесён с главного экрана в раздел «Подключение» рядом с уже существующим
  переключателем сохранения в Android Keystore (AES-GCM).
- Отступы Android 15+ учитывают клавиатуру вместе с системными панелями.

## Воспроизведение

В изолированном AsyncSSH/SFTP сервере отсутствует storage/shared. Новый integration-тест
проверяет отказ открытия этого пути, переход в домашний каталог, загрузку файла,
скачивание и побайтовое совпадение. Тест интерфейса проверяет отступ клавиатуры
и размещение поля пароля в настройках подключения.

Проверка физического Android/Termux пока не выполнена. Доступ Android к общей памяти
и установка Termux:API требуют проверки на устройстве. Фоновый мониторинг и сохранение
пароля существовали до этих изменений. Эта сборка остаётся тестовой 0.9.5 / code 14;
обновление метаданных до 0.9.6 отложено ради исправления файлового браузера.
