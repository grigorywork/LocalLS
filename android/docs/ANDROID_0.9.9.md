# LocalLS Android 0.9.9 — первая сборка с новым постоянным release-ключом

По решению владельца совместимость со старыми APK прекращена. Версия 0.9.9,
versionCode 18, начинает новую цепочку обновлений с постоянным RSA-ключом.
Следующие версии обязаны использовать тот же ключ и повышать versionCode.
Проверка сборки отклоняет другой сертификат; проверка выпуска требует предыдущий
release APK, кроме явно обозначенной первой версии этой цепочки.

Это release APK с debuggable=false. Функции приложения соответствуют проверенной
0.9.8; SSH-вход по ключу сохранён. Замена подписи не означает тестирования на телефоне.

Установка поверх старой debug-версии не поддерживается. Автоматического удаления
приложения и данных нет. Перед ручным переходом нужно сохранить доступ к серверу:
удаление приложения удалит его локальные настройки и SSH-ключи.

Ключ и пароль хранятся только в закрытом каталоге текущей среды вне Git.
Необходима защищённая резервная копия владельца вне этой среды для будущих выпусков.
Подробности: RELEASE_SIGNING.md. GitHub Actions пока выпускает debug-артефакты,
а не обновления этой release-цепочки.
