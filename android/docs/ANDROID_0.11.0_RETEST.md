Подпись прошла apksigner, структура APK, Manifest и выравнивание проверены. Package, сертификат и versionCode совместимы с release 0.10.0. APK не пересобирался, рабочий код не изменён.

Повторно выполнены 11 сетевых сценариев встроенного сервера — 0 ошибок, 0 пропусков:

- Передача двоичных файлов, mkdir, rename, delete.
- Отказ паролю, неверному пользователю и неизвестному ключу.
- Запрет выхода из общей папки, символьных ссылок, shell/exec и обратного перенаправления портов.
- Неизменный host fingerprint при перезапуске и закрытие порта после остановки.
- Проверка сервера клиентом LocalLS при отключённой командной оболочке.
- Отказ приватным/повреждённым/слишком коротким публичным ключам.
- Два одновременных клиента, по 8 МиБ каждый, побайтовая проверка.
- Докачка, кириллические имена с пробелом и пустые файлы.
- Ограничение четырьмя авторизованными сеансами и отключение активного клиента при остановке.
- Занятый порт и повторный запуск, запрет hardlink и direct-tcpip.
- Независимый клиент OpenSSH sftp: загрузка/скачивание >3 МиБ с StrictHostKeyChecking=yes и побайтовым сравнением.

Выполнены также существующие транспортные тесты и 7 Python-тестов правил обновления/первого релиза — без ошибок. Лог прогона: LocalLS-0.11.0-extra-tests.log.

Среда: JVM/Linux, реальные локальные SSH/SFTP-соединения. OpenSSH запускался отдельным процессом, не через клиентскую библиотеку LocalLS. Это не испытание на Windows.
