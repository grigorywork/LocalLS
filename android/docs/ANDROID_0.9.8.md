# LocalLS Android 0.9.8 (versionCode 17)

Исправления после 0.9.7:
- Можно сохранить профиль только с VPN-адресом, оставив неиспользуемый локальный адрес пустым. Активная точка подключения обязательно проверяется.
- Ошибки IP/имени сервера, пользователя, порта SSH и порта агента отображаются у соответствующих полей. Некорректная форма не записывается в настройки.
- Импорт адреса с двоеточием без порта (host:, ssh://host:, ssh://[::1]:) отклоняется вместо незаметной подстановки старого порта.
- Обработчик кнопки импорта устанавливается сразу после показа диалога, без ожидания отложенного onShow.
- Новые Robolectric-тесты проверяют импорт через реальный диалог, сохранение VPN-профиля и защиту сохранённых настроек от невалидного ввода.

Подпись: прежний локальный debug-сертификат, versionCode увеличен с 16 до 17. Совместимость с локальным APK 0.9.7 проверяется отдельно по пакету, подписи и коду версии. Ключ опубликованной 0.9.5 отсутствует; обновление этой официальной сборки не поддерживается данным APK.

Тесты на физическом Android/Termux и реальном Wi-Fi не выполнялись: устройство не подключено. Исходники и отчёт доступны в рабочей папке; публикация на GitHub не выполнена.
