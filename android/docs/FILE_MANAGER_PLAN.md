# Файлы и роли LocalLS — порядок этапов

Актуализировано 21 октября 2026 по повторному запросу владельца. Только Android APK; ключи, подпись и принятые файлы сохраняются.

1. **Текущий этап: файлы и сохранение.** Две области «Телефон» / «Сервер» доступны и клиенту, и телефону-серверу. Файлы и папки копируются в обе стороны. «Меню → Папка телефона» выбирает разрешённый Android каталог для области телефона, «Загрузки» открывает собственные загрузки LocalLS. Один набор направлений копирования, отдельные меню контекста областей. Папка автоматического приёма настраивается отдельно в «Мой сервер», без подтверждения каждого файла. Передачи и сервер работают фоновыми службами.
2. **Текущий этап: разделение ролей.** В режиме сервера чужое подключение, клиентская сеть и мониторинг чужого сервера скрыты/приостановлены. Общий ползунок «Подключаться к другому серверу» возвращает клиентские функции. Параметры не стираются; свой сервер и передачи не останавливаются.
3. **Проверка владельцем на двух телефонах.** Сохранить файл и папку в «Загрузки / LocalLS» и в выбранный доступный каталог; проверить направление копирования на обоих устройствах, отсутствие подтверждения каждого файла сервером, работу после сворачивания и роль сервера. Стендовые проверки не заменяют реальный Android/роутер/OEM.
4. **После успешной проверки и команды «давай последний мод»: расширение двухпанельного интерфейса.** Развивать удобство навигации и управления файлами по образцу привычного файлового менеджера. Использовать существующие функции, не добавлять дублирующие команды или второй экран тех же настроек. Конкретный объём уточняется по результатам предыдущего этапа; не обещать полную копию Total Commander.
5. **Следом: другая Wi-Fi сеть без смены ключей.** Уже реализованы сохранение клиентской пары и проверенного fingerprint при смене адреса того же сервера, а также восстановление старой привязки. Следующее расширение этого сценария — после работы с файлами. Оба устройства должны иметь разрешённый маршрут; локальный IP не обеспечивает доступ через произвольный интернет. Не подменять проверку ключа сервера, не создавать новые пароли/пары для обычной смены адреса.

0.11.14 исправляет текущий этап: независимость папок телефона и серверного автосохранения, сохранение истории навигации, обработку устаревшего выделения, переименование собственных загрузок и неполное скрытие клиентских настроек. Расширение сетевых возможностей не выполнялось.

0.11.15 связывает файловый экран с конкретным подключением: смена адреса, пользователя, порта, fingerprint или роли сбрасывает устаревшее серверное состояние; старый результат выбора файлов не отправляется новому серверу. Уже поставленные задания сохраняют своё назначение.

Android ограничивает доступ к защищённым папкам и общему корню загрузок. «Любая папка» здесь означает каталог, который системный выбор Android разрешает приложению читать и записывать. Доступ ко всем чужим файлам без разрешения не добавляется. Сервер предоставляет только свою папку LocalLS.

0.11.21: расширение списка разрешено командами владельца «выполняй» и замечанием о мелком интерфейсе. Реализованы фильтр, сортировка, обратный выбор, сведения; крупные подписи и текстовая навигация. Сетевой этап 5 отложен прямым ответом владельца «это пока не надо». Настройки VPN/разных сетей не добавлять до новой команды.
