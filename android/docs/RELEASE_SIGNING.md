# Подпись APK LocalLS

Debug certificate предназначен для разработки. Для распространения APK нужен постоянный
ключ владельца; Google Play не принимает debug-подпись. Источник:
https://developer.android.com/studio/publish/app-signing

В исходном BUILD_REPORT.md указана debug-подпись. Эта запись относится к старой сборке,
а не подтверждает подпись нового APK после локальных изменений.

Release-конфигурация теперь читает только переменные окружения:

- LOCALLS_RELEASE_STORE — абсолютный путь к приватному keystore вне репозитория;
- LOCALLS_RELEASE_STORE_PASSWORD — пароль keystore;
- LOCALLS_RELEASE_KEY_ALIAS — alias постоянного ключа;
- LOCALLS_RELEASE_KEY_PASSWORD — пароль ключа.

Не вставляйте пароль/ключ в чат, build.gradle, GitHub, диагностический отчёт или команду
с открытым аргументом. Используйте защищённое окружение владельца/CI. Файлы *.jks,
*.keystore и signing.properties исключены из Git. Ничего не подписывается случайным
новым release-ключом автоматически. Без всех четырёх значений preReleaseBuild завершится
ошибкой; debug-сборка использует штатную тестовую подпись.

После установки переменных: gradlew.bat :app:assembleRelease.
Проверьте сертификат через apksigner verify --verbose --print-certs и убедитесь, что это
ожидаемый сертификат владельца. Храните резервную копию ключа и паролей отдельно.

## Обновление существующей установки

Обычный APK с тем же applicationId, но другим сертификатом не обновит установленный
APK: Android проверяет совместимость подписей. Переход с debug на новый release-ключ
не обещает бесшовного обновления. Сначала сохраните публичный профиль сервера и отдельно
проверьте доступ/пароли; экспорт профиля не экспортирует секреты Keystore. Только после
проверенного плана миграции можно менять установленную сборку. Удаление приложения
удаляет локальные данные и ключи Android Keystore.

Повышение versionCode само по себе не исправляет несовпадение подписей. При подготовке
реального выпуска также назначьте версию/код выше последнего опубликованного APK.
