# LocalLS Android 0.11.2 — проверка запуска

LocalLS Android 0.11.2: исправление скрытого отказа запуска телефонного сервера.

- Ошибка проверки публичного ключа теперь видна рядом с кнопкой запуска и попадает в диагностику.
- Поддержан импорт публичного ключа, разбитого на строки при пересылке.
- Диагностика содержит состояние запуска даже без исключения; добавлен контроль зависшего запуска.
- Вход только по ключу, без Termux. Выравнивание кнопок из 0.11.1 сохранено.
