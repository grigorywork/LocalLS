## Функции

Компактный фиолетовый интерфейс, реальные графики SFTP скорости и SSH задержки,
полноэкранная по высоте правая шторка шириной 50%, пять цветовых тем, облако со стрелой.
Вложения через SAF или Android «Поделиться», подтверждение списка/папки перед отправкой,
переход в папку сервера, история, foreground service и сворачивание через Home.
Название LocalLS; package сохранён для обновления и сохранения настроек.

VPN использует публичные CONNECT_VPN / DISCONNECT_VPN broadcasts установленного
официального Tailscale. Статус проверяется через Android ConnectivityManager;
первоначальный вход и VPN consent выполняются в Tailscale. Тумблер не переключает
удалённо VPN компьютера или Realme. Для общей сети нужно настроить все три клиента
в одной tailnet; обычный Tailscale сохраняет домашнюю локальную сеть.

Дополнительный графический мастер на Realme использует официальный Termux SAF/RUN_COMMAND:
папка, явное задание пароля, подготовка OpenSSH, проверка входа и экспорт публичного
профиля для Samsung. Штатная настройка Termux сохранена. Конфигурация, существующие
host keys, пароль по умолчанию, работающий sshd и автозапуск не заменяются. Новый
пароль задаётся только по явному переключателю с подтверждением. Пароль не передаётся
в команды и профиль; сохраняется штатный бинарный хеш Termux в его приватной папке.
Для первого запуска требуется установка/инициализация Termux и системные разрешения
на Realme. Терминала в LocalLS нет, ручной ввод команд не нужен; первый запуск Termux
показывает его штатный экран. Ограничения описаны в docs/SERVER_SETUP.md.

## Найдено и исправлено

- Настроены реальные JDK/SDK/build-tools, восстановлен официальный wrapper в базовой v0.8.
  Первая сборка v0.8 и исправления безопасности описаны в docs/BUILD_REPORT_v0.8_BASELINE.md.
- Нативный back API 33+ с сохранением совместимости Android 7–12; исправлена ошибка lint
  GestureBackNavigation, сохранено закрытие шторки без выхода из приложения.
- Атрибут светлой navigation bar API 27 не использован на API 24; исправлена ошибка minSdk.
- Исправлены ссылки нового мастера на стиль кнопок и lint WrongConstant для SAF grants.
- Gradle требует сетевой доступ даже для локального lock handler: сборка запущена
  с разрешённой сетью, исправлена ошибка usable wildcard IP среды.
- Удалено повторное чтение вложений из первоначального Intent при восстановлении
  уже отправленного/переданного пустого списка; исключена повторная отправка после recreate.
- URI ограничены content:// и числом 64, имена файлов очищены; ошибки выдачи доступа
  перехватываются, пароль остаётся в one-shot SessionPassword вместо Intent/Bundle.
- Темы применяются к графикам и тексту; проводник не пересоздаётся во время передачи.
- VPN отображает фактическую сеть, а не факт отправки команды; проверяется другой VPN.
- Мастер не дополняет существующие SSH host keys: это предотвращает изменение
  выбранного отпечатка после следующего штатного перезапуска sshd.
- RUN_COMMAND фиксирован и не содержит пользовательских строк/пароля. Callback приватный,
  явный, одноразовый, с nonce; сырые stdout/stderr не публикуются.
- Импорт блокирует изменение уже доверенного ключа и очищает сохранённый старый пароль.
- Пароли в UI не сохраняются в состоянии Activity. Состояние экспорта содержит только
  публичные параметры и переживает системный выбор файла.

## Что не проверено и ограничения

Физические Samsung Galaxy A01 и Realme GT Neo 2 не подключены. Подключение к
192.168.1.82, настоящий аккаунт Tailscale, VPN на ПК/телефоне/Realme, ограничения
батареи Samsung/Realme, файлы 2–5 ГБ, работа с выключенным экраном на физических
устройствах не проверены. Реальная домашняя рабочая схема Realme не затрагивалась.

Полная подготовка OpenSSH с нуля через Termux не проверена: тест требует системного
разрешения корневой папки Termux, которое не было предоставлено в тестовой среде.
Автоматический тест TermuxBootstrapInstrumentedTest пропущен, а не засчитан успешным.

Foreground transfer живёт в FilesActivity: Home поддерживается; уничтожение экрана
отменяет очередь. При обрыве overwrite возможен частичный целевой файл. Атомарная
передача и перенос очереди в полноценный service — основа v1.0, см. docs/V1_0_FOUNDATION.md.
Смена темы откладывает recreate во время активной передачи. Realme Agent остаётся
отдельным штатным механизмом управления; его HTTP/TLS ограничения сохранены.
