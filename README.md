# LocalLS

SSH/SFTP-клиенты для Android и Windows, работающие с существующим сервером Termux/OpenSSH.

Исходники Android расположены в `android/`. Сохранённые версии импортированы отдельными
коммитами и тегами. Это импорт фактически сохранившихся снимков проекта, а не история
каждого изменения во время разработки. Итоговые APK публикуются отдельно в GitHub Releases.

Рабочая конфигурация сервера и единственный механизм запуска sshd сохраняются.
Пароли, токены, ключи подписи, пользовательские данные и кэши сборки не публикуются.
