Первый предварительный выпуск **встроенного SFTP-сервера без Termux**. Серверный режим требует Android 8+.

### Как запустить

«Этот телефон — сервер» → укажи публичный ключ компьютера (.pub) → «Включить сервер». В WinSCP выбери SFTP и введи показанные адрес, порт и пользователя. Сверь fingerprint.

На Windows ключ можно создать командой `ssh-keygen -t rsa -b 3072`. В телефон переносится только id_rsa.pub; закрытый ключ остаётся на компьютере. Поддерживается RSA 3072+ и ECDSA P-256; Ed25519 пока не поддерживается.

### Возможности

- Работает внутри APK, без Termux и установки sshd.
- Изолированная папка LocalLS; системный импорт файлов, просмотр и сохранение полученных файлов на телефон.
- Авторизация только по ключу, постоянный зашифрованный host key.
- Shell/exec, перенаправление портов, ссылки и выход за пределы папки запрещены.
- Уведомление и явная остановка; автозапуск выключен.

### Ограничения первой версии

Прямой доступ к произвольной папке телефона через SAF не реализован. Удаление LocalLS удаляет его серверную папку и host key. Android 15+ может ограничить dataSync-службу шестью часами в сутки; также действует энергосбережение устройства. Linux-команд и метрик Termux нет.

**На настоящем телефоне и с Windows ещё не проверено.** Сетевые тесты выполнялись с реальным клиентом JSch в сборочной среде, а Android-экраны — Robolectric. Это предварительный релиз для проверки серверного режима на устройстве.

Проверки: 50 JVM-тестов и 7 Python-тестов прошли; lint — 0 ошибок, 18 предупреждений. APK имеет прежнюю постоянную release-подпись, versionCode 20; совместимость обновления с release 0.10.0 проверена.
