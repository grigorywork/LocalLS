# LocalLS Android 0.11.0 — встроенный SFTP без Termux

Первый выпуск встроенного файлового сервера. VersionCode 20, постоянный release-сертификат тот же, что у 0.9.9 и 0.10.0. Серверный режим требует Android 8 (API 26) или новее; остальные функции приложения сохраняют minSdk 24.

## Запуск

1. Нажать «Этот телефон — сервер». Откроется встроенный режим, без запуска Termux.
2. Указать пользователя (по умолчанию localls), свободный порт (по умолчанию 8022) и публичный ключ компьютера. Можно загрузить файл .pub.
3. Для Windows: `ssh-keygen -t rsa -b 3072`. Закрытый id_rsa остаётся на компьютере. В LocalLS переносится только id_rsa.pub. Поддерживается RSA от 3072 бит или ECDSA P-256; Ed25519 в этой первой версии не поддерживается.
4. Нажать «Включить сервер». Приложение покажет адреса и SHA-256 fingerprint.
5. В WinSCP выбрать SFTP, указать адрес телефона, порт, пользователя и соответствующий закрытый ключ. При первом подключении сверить fingerprint с экраном телефона.

Сервер слушает IPv4-интерфейсы телефона (Wi-Fi/VPN). Проброс портов роутера не настраивается. Доступ зависит от сети, режима изоляции клиентов Wi-Fi, VPN и разрешений Android.

## Файлы

Корень SFTP `/` — отдельная папка внутри данных LocalLS. Доступа ко всем файлам телефона нет. Кнопка «Добавить файлы» копирует выбранные документы в эту папку. Совпадающие имена не перезаписываются. «Файлы сервера / сохранить на телефон» позволяет просматривать полученные файлы и сохранять их через системный выбор места назначения.

Удаление приложения удалит содержимое этой папки и серверный host key. Это не произвольная папка SAF: прямое предоставление выбранного внешнего дерева в этой версии не реализовано.

## Безопасность и жизненный цикл

- Apache MINA SSHD 2.20.0 (Apache-2.0), лицензии и notices включены в APK.
- Только public-key authentication. Парольная авторизация, shell/exec, перенаправление портов, создание hard/symbolic links запрещены.
- Виртуальная файловая система ограничена общей папкой; существующие символические ссылки на пути отклоняются.
- Лимиты авторизации, числа соединений/каналов и времени простоя.
- Отдельная RSA-идентичность сервера хранится зашифрованной Android Keystore, за пределами общей папки. При повреждении сохранённого секрета автоматической смены host key нет.
- Служба foreground с уведомлением и кнопкой остановки, без автоматического перезапуска/запуска после загрузки телефона. Остановка закрывает сервер и соединения.
- Тип службы dataSync: Android 15+ может ограничить её работу шестью часами в сутки. Экономия энергии производителя также может вмешиваться. CPU wake lock ограничен шестью часами и освобождается при остановке.
- Linux-команды и системные метрики Termux не предоставляются. Клиент LocalLS умеет распознавать доступный SFTP при отключённой командной оболочке.

## Проверки

Сетевые тесты с реальным SSH/SFTP-клиентом JSch: двоичная передача >1 МиБ в обе стороны, mkdir/rename/delete, неправильные имя/ключ/пароль, запрет команд/перенаправления/ссылок/выхода из общей папки, закрытие порта и сохранение fingerprint при перезапуске, проверка соединения клиентом LocalLS. Отдельные тесты границы локального браузера, экрана управления и повреждённого host key.

Android APK, lint, компиляция инструментальных тестов и подпись проверяются при сборке. Физический Android не подключён: запуск службы, доступ по Wi-Fi с Windows, файловые провайдеры и энергосбережение на настоящем телефоне ещё требуют проверки. Это первый предварительный выпуск серверного режима; успешные JVM-тесты не заменяют такой проверки.
