LocalLS Android 0.11.4 — сначала телефон 1, потом телефон 2.

[Инструкция для двух телефонов](https://github.com/grigorywork/LocalLS/blob/android-v0.11.4/android/app/src/main/assets/phone-setup.txt). Она также входит в APK и открывается без интернета: «Мой сервер → Настроить сервер → Инструкция: два телефона».

- Телефон 1 сам показывает адрес Wi-Fi до запуска сервера; адрес не нужно искать в старой инструкции.
- При пустом разрешённом ключе сервер запускается в ожидании телефона 2. Порт открыт, но вход закрыт для всех ключей и паролей.
- Затем на телефоне 2 настраивается подключение и создаётся его ключ. Владелец выбирает публичный .pub на телефоне 1 и явно нажимает «Разрешить».
- Первый ключ добавляется к ожидающему серверу без перезапуска. Для замены уже разрешённого ключа сервер по-прежнему нужно остановить.
- Опубликована общая инструкция без персональных адресов, ключей и конфигурации владельца. Данные приложения автоматически на GitHub не отправляются.

versionCode 24, прежняя release-подпись. Совместимость APK с 0.11.3 проверена; установка поверх, без удаления данных. Для полного начала новой пары старый разрешённый ключ нужно очистить вручную при остановленном сервере, как описано в инструкции. На физическом Android в этой среде сборка не проверялась, поэтому публикация предварительная.
