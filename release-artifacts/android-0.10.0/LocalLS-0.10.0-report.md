# LocalLS Android 0.10.0 — перенос параметров и удобная навигация

versionCode 19. Та же постоянная release-подпись, что у 0.9.9. Только Android.

Семь изменений:
1. Экспорт сохранённых адресов Local/VPN, пользователя, режима и портов в JSON через системный выбор файла.
2. Импорт этого файла на устройство. SSH-ключи, пароль, токен агента и доверенные отпечатки не экспортируются и не импортируются.
3. Проверка формата и версии файла, ограничение 8 КБ, проверка адресов/портов и предварительный просмотр перед применением. Неверный файл не изменяет настройки. Старый токен агента очищается, фоновое наблюдение выключается.
4. Копирование готового SSH- или SFTP-адреса, включая скобки для IPv6.
5. Последняя успешно открытая папка запоминается отдельно для адреса, порта и пользователя. Старый глобальный путь больше не переносится на другой сервер. Для новой точки начальная папка — домашняя.
6. До 20 избранных папок на точку подключения, переход к ним и удаление закладок. Добавить можно только успешно открытую папку.
7. Отдельная кнопка «Домой» в файловом браузере, в том числе для восстановления после ошибки пути.

Использование: сохраните параметры на главном экране → «Перенос параметров» → сохраните файл. На другом устройстве загрузите файл, проверьте значения и примените. Затем настройте SSH-ключ и проверьте fingerprint сервера. В этом чате нет доступа к настройкам установленного телефона, поэтому они автоматически не считывались.

Проверки: JVM-тесты правил переноса, защиты секретов и изоляции папок; существующие тесты SSH/HTTPS и интерфейса; release APK и lint. Итоговые числа и SHA-256 записаны рядом с APK. Физическое устройство не подключено, установка на телефоне не выполнена.

Публикация GitHub заблокирована: доступное подключение возвращает HTTP 403 Resource not accessible by integration при создании дерева исходников и релиза. Готовые файлы сохраняются локально; успешная публикация не заявляется.
