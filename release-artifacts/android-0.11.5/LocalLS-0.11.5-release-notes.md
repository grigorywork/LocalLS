LocalLS Android 0.11.5 — сохранение принятых файлов и цветные статусы.

На телефоне-сервере открой «Файлы сервера / сохранить на телефон», нажми на принятый файл и выбери «В Загрузки → LocalLS» (Android 10+). После зелёного сообщения копия доступна в системных «Файлы → Загрузки → LocalLS». Для Android 8–9 и другого места сохранения используется системный выбор документа.

- Прямое сохранение через MediaStore в Загрузки/LocalLS на Android 10+.
- Копирование выполняет foreground-служба с прогрессом и уведомлением. Закрытие экрана файлов не отменяет копию.
- Успех появляется после закрытия выходного потока и завершения публикации. Повреждённая/неполная новая запись MediaStore удаляется при обработанном сбое; выбранные пользователем документы автоматически не удаляются.
- Ошибки видны на красной плашке с кнопкой безопасной диагностики. Оригинал принятого файла остаётся в LocalLS.
- Работающий сервер выделен зелёным, ожидание и сохранение — жёлтым, ошибка — красным. Инструкция в APK обновлена.

[Инструкция](https://github.com/grigorywork/LocalLS/blob/android-v0.11.5/android/app/src/main/assets/phone-setup.txt). Прежняя release-подпись, versionCode 25, установка поверх 0.11.4. Подключение и принятые файлы не нужно сбрасывать. Физическое устройство в этой среде недоступно; публикация предварительная.
