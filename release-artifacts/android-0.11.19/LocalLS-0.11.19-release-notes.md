0.11.19 / versionCode 39. Подписанный APK для установки поверх 0.11.18 без удаления приложения. Сертификат выпуска прежний, ключи доступа и настройки не сбрасываются.

- Повторная команда локального сохранения не создаёт вторую копию. Недавний завершённый запрос не повторяется после пересоздания службы в том же процессе; намеренная новая копия остаётся доступной.
- Пустая команда не сбрасывает уже выполняемое сохранение. После дополнительных команд служба корректно останавливается с последним startId.
- Блокировка питания освобождается при завершении, отказе запуска и тайм-ауте Android. Остановленная операция не публикует поздний прогресс. Запоздалый тайм-аут после завершения не заменяет успешный результат ошибкой.
- Временные файлы незавершённых загрузок скрыты в списке принятых. Их нельзя экспортировать даже по сохранённому точному пути; обычные скрытые файлы доступны.

Проверки: 203 JVM-теста + 7 Python-проверок, 0 ошибок и пропусков. Добавлены 13 сценариев, в том числе нехватка места после частичной записи, запрет foreground, тайм-аут, обрыв скачивания и отказ исходного потока. На 0.11.18 шесть сценариев воспроизвели сбои; исправленные сценарии проходят. Lint: 0 ошибок, 26 предупреждений. Проверены apksigner/zipalign, прежние package и сертификат, рост versionCode относительно подписанной 0.11.18.

Android-сценарии — Robolectric, SSH/SFTP и HTTPS — настоящие сокеты на изолированных loopback IP. ENOSPC моделируется ошибкой потока после частичной записи, диск среды не заполнялся. Физический телефон/Android AVD, реальные Wi-Fi/VPN, аппаратный Keystore и OEM/Doze не проверены. Дедупликация локального экспорта ограничена последними 256 успешными ID текущего процесса; восстановления заданий после убийства процесса нет.
