# LocalLS Android 0.11.9 — проверка завершения передачи

LocalLS Android 0.11.9 — проверка завершения передачи файлов и папок.

- Копирование папки пропускает служебные временные файлы незавершённых загрузок. Обычные скрытые файлы сохраняются.
- Отмена на последнем блоке скачивания считается отменой. Завершение счётчика прогресса больше не может отменить уже полученный запрос остановки загрузки или скачивания.
- Перед публикацией скачанного файла повторно проверяются тип, размер и время изменения исходника. Обнаруженное изменение требует повтора; копия не объявляется готовой. Это проверка метаданных, а не контрольной суммы или снимка файловой системы.
- Проверен обрыв загрузки остановкой сервера, затем успешный повтор с прежней идентичностью сервера и ключом клиента.

Установи APK поверх 0.11.8 на оба телефона без удаления приложения и очистки данных. После обновления включи сервер вручную. Подпись прежняя, versionCode 29 > 28. Ключи и выбранные папки не сбрасываются.

[Настройка двух телефонов](https://github.com/grigorywork/LocalLS/blob/android-v0.11.9/android/app/src/main/assets/phone-setup.txt) также встроена в APK.

106 JVM-тестов и 7 Python-тестов прошли без ошибок и пропусков, lint без ошибок. Сборки release и instrumentation APK прошли; установка и тестирование на физическом телефоне не выполнялись: подключённого устройства нет.

При внезапном обрыве скрытая временная запись на сервере может остаться, она не выдаётся за готовый файл. Повтор папки запускает задание целиком и может создать дополнительные копии уже завершённых частей. Восстановления сетевой очереди после принудительной остановки пока нет.


Проверки: JVM {'tests': 106, 'failures': 0, 'errors': 0, 'skipped': 0}, Lint {'Error': 0, 'Warning': 26}; 7 Python-тестов правил подписи/обновления. Аудиты проекта и архитектуры: 0 ошибок, 84 production-класса, 5 модулей. Физический телефон по ADB отсутствует, instrumentation APK только собран.

Четыре регрессии воспроизведены тестами на прежней реализации: включение незавершённого временного файла в список для копирования папки; успех при отмене скачивания на последнем блоке; пропуск изменения mtime исходника во время чтения; отмена загрузки, которую monitor.end() менял обратно на продолжение. После исправления все тесты проходят. Первый прогон трёх тестов: reproduce.log, отдельный прогон четвёртого: reproduce-upload.log в рабочем окружении. Пятый новый тест использует настоящий SSH/SFTP-сервер на loopback: сервер останавливается после первого блока многоблочного файла; проверяются исключение и отсутствие окончательного имени. Сервер снова запускается с прежним host key; повтор с тем же клиентским ключом и pin завершается, байты совпадают, незавершённые служебные записи отсутствуют в списке копирования. Этот тест не заменяет проверку фоновой работы на Android/OEM.

Изменения ограничены SftpClient.TreeSession: фильтр зарезервированных служебных имён, необратимый в рамках передачи флаг отмены в progress callback, повторный lstat перед успешным возвратом скачивания.
