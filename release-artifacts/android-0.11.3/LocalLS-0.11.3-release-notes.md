LocalLS Android 0.11.3 — «Мой сервер» и «Подключение».

- «Мой сервер» — приём файлов на этот телефон. Состояние приёма отделено от удалённого подключения.
- «Подключение» — файлы другого устройства: адрес, порт, пользователь, ключ доступа, проверка и передача файлов собраны в одном блоке.
- Удалены дублирующие входы «Текущий сервер», старое меню SSH-агента, быстрые shell-команды/iperf и переход к старой настройке Termux.
- В параметрах приложения больше нет копий адресных полей и ключей. На экране ключа убраны старый парольный bootstrap и настройки HTTPS/HTTP-агента; импорт и удаление ключа доступны через «Дополнительно».
- Ошибка отсутствующего ключа указывает реальный путь: «Подключение → Адрес и ключ → Ключ доступа».
- Для новой установки адрес пустой, пользователь localls. Сохранённые подключения и ключи при обновлении не сбрасываются.

Установка поверх 0.11.2, versionCode 23. Постоянная release-подпись сохранена. Проверка на физическом телефоне в этой среде недоступна; сборка опубликована предварительной.
