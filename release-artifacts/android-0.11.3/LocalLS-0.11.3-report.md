# LocalLS Android 0.11.3 — разделение ролей

LocalLS Android 0.11.3 — «Мой сервер» и «Подключение».

- «Мой сервер» — приём файлов на этот телефон. Состояние приёма отделено от удалённого подключения.
- «Подключение» — файлы другого устройства: адрес, порт, пользователь, ключ доступа, проверка и передача файлов собраны в одном блоке.
- Удалены дублирующие входы «Текущий сервер», старое меню SSH-агента, быстрые shell-команды/iperf и переход к старой настройке Termux.
- В параметрах приложения больше нет копий адресных полей и ключей. На экране ключа убраны старый парольный bootstrap и настройки HTTPS/HTTP-агента; импорт и удаление ключа доступны через «Дополнительно».
- Ошибка отсутствующего ключа указывает реальный путь: «Подключение → Адрес и ключ → Ключ доступа».
- Для новой установки адрес пустой, пользователь localls. Сохранённые подключения и ключи при обновлении не сбрасываются.

Установка поверх 0.11.2, versionCode 23. Постоянная release-подпись сохранена. Проверка на физическом телефоне в этой среде недоступна; сборка опубликована предварительной.

Проверки: JVM {'tests': 64, 'failures': 0, 'errors': 0, 'skipped': 0}; Python — 7 тестов подписи/правил обновления. Статический аудит: 0 ошибок/предупреждений. Архитектурный аудит: 0 ошибок. Lint: {'Error': 0, 'Warning': 16}.

Проверены независимые настройки локального сервера и удалённого профиля; сохранение актуальной точки подключения перед открытием ключей; отсутствие удалённых команд в дереве интерфейса; геометрия/центровка кнопок при масштабе шрифта 1 / 1.5 / 2 и темах оформления. Рендеры находятся в ui-previews.zip. Отдельно повторно пройдены SSH/SFTP-интеграции, проверка ключей и ограничения файловой папки. Android instrumentation APK собран, на устройстве не запускался.

Локальный статус обновляется независимо от опроса удалённого сервера. Постоянное хранилище ключей и каталог файлов сервера не изменены этой ревизией. Старые настройки Termux/агента исключены из обычного интерфейса; соответствующие транспортные возможности и старые экранные классы остаются в исходниках для дальнейшей разработки других версий.
