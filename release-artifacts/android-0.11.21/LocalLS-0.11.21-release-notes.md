Экран файлов теперь читается крупнее: кнопки от 16 sp, имена файлов и заголовки 18 sp. Команды «Выше», «Обновить», «Меню» заменили одиночные символы. Кнопки копирования закреплены снизу; большие системные шрифты переносят команды на новые строки, области файлов прокручиваются.

Верхний ряд убран. Выбор файлов, отправка папки, выбор папки телефона и загрузки собраны в «Телефон → Меню». Телефон и сервер сохраняют отдельные области и настройки.

Добавлены фильтр по имени, сортировка по имени/размеру, обратный выбор и сведения. Выбор всех относится только к видимым элементам; скрытые снимаются с выбора. Папки остаются первыми, сортировка сохраняется отдельно для двух областей.

Нажатие на сообщение передачи открывает подробности без обрезки и повтор, если неудачное задание ещё сохранено в процессе. Общая ошибка со скриншота сама по себе не устанавливает причину отказа; исправление всех возможных отказов передачи этим выпуском не заявляется.

Подпись — прежний постоянный сертификат, versionCode увеличен до 41. Инструкция двух телефонов обновлена в APK и приложена отдельно. Сетевые функции между разными Wi-Fi/VPN отложены по просьбе владельца. Физические телефоны в среде разработки не подключены.
