LocalLS Android 0.11.7 — исправление очереди автосохранения.

В 0.11.6 первый файл с ошибкой записи или удалённым исходником мог задерживать остальные. Теперь независимые файлы продолжают сохраняться, а неудачные остаются для повтора.

- Удалённые исходники пропускаются с сообщением; они не блокируют следующие загрузки.
- Ошибка одного файла не задерживает остальные. «Повторить сохранение» обрабатывает только ожидающие файлы.
- Повторно присланный файл под прежним именем сохраняется, даже если прежняя запись была пропущена как удалённая.
- Объединены повторные запросы к фоновому исполнителю; проверен приём пачки файлов во время занятого копирования.
- Существующая очередь 0.11.6 открывается без сброса базы, ключей и настроек.

Установи APK поверх 0.11.6 на оба телефона, данные не очищай. На телефоне-сервере после обновления включи сервер; зависшие ожидающие сохранения будут обработаны. Закрытый ключ и разрешённый публичный ключ пересоздавать не нужно.

[Инструкция: два телефона](https://github.com/grigorywork/LocalLS/blob/android-v0.11.7/android/app/src/main/assets/phone-setup.txt). Инструкция также встроена в APK.

95 JVM-тестов и 7 Python-тестов прошли; lint без ошибок. Прежняя release-подпись, versionCode 27; совместимость обновления с 0.11.6 проверена. Физический телефон в среде разработки не подключён, установка и аппаратные тесты не выполнялись.
