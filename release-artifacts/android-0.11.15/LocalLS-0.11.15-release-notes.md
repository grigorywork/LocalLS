Устанавливается поверх 0.11.14 без удаления приложения. Пакет и постоянный release-сертификат прежние; versionCode 35 > 34.

- Файловый экран и новое задание используют одно подключение и один проверенный fingerprint. Изменение общих настроек больше не отправляет старое выделение на другой сервер.
- После смены адреса, порта, пользователя, fingerprint или роли экран обновляется. Сохранённое состояние чужого сервера не восстанавливается; папка телефона сохраняется.
- Если подключение изменено, пока открыт системный выбор файлов/папки, приложение просит выбрать заново. Обычное пересоздание экрана с тем же подключением сохраняет назначение.
- Подтверждение создания папки, переименования и удаления на сервере проверяет актуальность подключения. Отложенное чтение выбранных файлов не отправляет их после перехода в другую папку.
- Уже поставленная передача сохраняет исходное назначение. Смена профиля не перенаправляет её; для остановки есть отмена очереди.

Проверки: 148 JVM-тестов и 7 Python-тестов, без ошибок и пропусков. На стенде проверены два SSH/SFTP-сервера с разными адресами, передача только исходному адресату, смена роли, fingerprint, восстановление экрана и выбор папки. Lint без ошибок, проверки подписи и совместимости обновления пройдены. Телефоны, установка на них и реальный Wi-Fi в среде разработки недоступны.

Инструкция настройки двух телефонов встроена в APK и опубликована с исходниками. Новые сетевые функции для произвольных Wi-Fi сетей остаются следующим этапом по плану.
