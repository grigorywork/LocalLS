# LocalLS Android 0.11.1 — ревизия запуска сервера и выравнивания

versionCode 21. Постоянный release-сертификат сохранён; обновление предназначено для установки поверх 0.11.0 без удаления данных.

## Исправление запуска

На фотографии устройства показана общая ошибка при запуске SFTP. В тесте воспроизведён дефект: в свежем процессе без системных свойств user.name и user.home инициализация Apache SSHD падала до открытия порта:

`ExceptionInInitializerError → IllegalArgumentException: No username available`

Дефолтный ServerBuilder создаёт desktop authorized_keys authenticator даже до замены его прикладным обработчиком. Теперь до инициализации ServerBuilder задаются имя пользователя SSHD и resolver домашней папки. Политика входа не меняется: используется только явно разрешённый публичный ключ, а не файл authorized_keys из общей папки.

Регрессионный тест запускается в отдельной JVM, удаляет desktop-свойства, включает Android-режим SSHD и проверяет открытие порта. До исправления тест падал, после — проходит. Это симуляция отсутствующих свойств Android, не запуск на физическом телефоне. Совпадение с причиной на устройстве без его диагностического отчёта не доказано.

## Диагностика

На экране сервера появилась кнопка «Скопировать диагностику запуска». Для ошибок показываются этапы PUBLIC_KEY / HOST_KEY / NETWORK / POWER / FOREGROUND. Копируются типы исключений и кадры стека, но не сообщения исключений, ключи, пароли или введённые поля. Сохранённый host key не меняется автоматически.

## Интерфейс

- Дублирующая кнопка «Меню» убрана с главного экрана; остаётся «Настройки».
- Плитки рисуют иконку и подпись единым блоком, центрированным по вертикали и горизонтали.
- Выравнивание действует на главном экране, действиях текущего сервера и остальных кнопках-плитках.
- Строки и заголовки бокового меню остаются прежними.
- Высота плиток рассчитывается с учётом иконки и фактического числа строк; текст не прижимается к нижнему краю.

Проверяются серверные сценарии с JSch и независимым OpenSSH, запуск без desktop-свойств, геометрия содержимого кнопок при разных размерах шрифта, правила подписи и обновления. Финальные числа, SHA-256 и результаты lint записаны рядом с APK.

Физический Android через ADB не подключён: установка и проверка на телефоне в этой среде невозможны. Ограничения серверного режима 0.11.0 сохраняются (отдельная папка приложения, Android 8+, dataSync-служба и ограничения энергосбережения).
