# LocalLS 0.9.5 — объединение версий

Основа: Android 0.9.4 и Windows/Fedora 0.1.1 из `main` 515c640.
Исправления интерфейса и модулей: ветка `codex/android-ui-modules` 9465032.

| Область | Результат объединения |
|---|---|
| Android | core/data/transport/ui/app, центрирование рисунков, крупный шрифт, доступность, ресурсы статусов |
| SSH | Новый строгий publickey-вход, создание/импорт ключей, проверенное добавление authorized_keys |
| Агент | HTTPS с pin сертификата; старый HTTP требует отдельного явного разрешения |
| Windows/Fedora | Сохранены новые ключи/HTTPS и функциональность серверного мастера; центрированы 9 SVG-рисунков |
| Версия | VERSION, Android 0.9.5/code 14, package/lock/UI двух настольных клиентов, EXE/RPM 0.9.5 |
| Проверки | Общий version gate; Android тесты/сборка/Lint; настоящие Windows installer и Fedora RPM с runtime fixture |

ApplicationId, desktop appId, RPM package name, формат публичного профиля,
Keystore и существующий механизм запуска sshd сохранены.
Приватные SSH-ключи и ключи подписи не добавлялись в Git.

## Проверка

Фактические результаты сборок и ограничения фиксируются в отчётах артефактов
и GitHub Actions. Предыдущие BUILD_REPORT сохранены как BASELINE и не используются
как подтверждение новой 0.9.5. Android, Windows и Fedora gates завершились успешно; совместимость подписи
Android с 0.9.4 независимо подтверждена. Ссылки v0.9.5 относятся к общему выпуску.
