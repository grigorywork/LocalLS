# LocalLS Fedora 0.9.5

Версия для Fedora x86_64: клиент SSH/SFTP и графическое управление штатным
OpenSSH-сервером текущего компьютера. Android и Windows остаются отдельными проектами.

[Готовый комплект и инструкции RU/EN](../distributions/Fedora/README.md) ·
[Отчёт сборки](BUILD_REPORT.md)

Клиент: две панели, прикрепление и отправка файлов, выбор файлов в разных папках,
скачивание в выбранную локальную папку, история и фактический график скорости.
Темы и формы кнопок сохранены. Закрытие окна сворачивает его; в GNOME окно можно
вернуть из обзора приложений без расширения трея. Полный выход — в настройках.

Мастер: установка openssh-server через DNF; запуск, остановка и перезапуск
существующего sshd.service; отдельное включение/отключение автозапуска;
стандартное разрешение SSH:22 в зоне firewalld по умолчанию; реальный SSH/SFTP-вход
на 127.0.0.1 и экспорт профиля без секретов для Android/Windows. Пароль учётной
записи и Wi-Fi настраиваются в штатных графических окнах GNOME/KDE.
Новые SSH-службы, агент и конкурирующий механизм автозапуска не создаются.

Административные команды доступны только через root-owned помощник RPM
`/usr/libexec/localls-server-helper.py`, фиксированный список аргументов и pkexec.
Приложение работает обычным пользователем. Renderer изолирован, sandbox включён;
изменившийся SSH-ключ блокирует отправку пароля. Без шифрующей связки ключей
сохранение секретов отключено, backend basic_text не допускается.

Tailscale: интеграция официального установленного Linux-клиента, реальный статус,
переключение с системным подтверждением и переход к официальному входу в браузере.
Учётная запись и настройка tailnet необходимы отдельно.

## Сборка на Fedora

Проверено в Fedora 44 x86_64: Node.js 22, Electron 44.7.0,
electron-builder 26.15.3, rpm-build. Зависимости окружения перечислены
в `tools/Fedora.Dockerfile`; runtime-зависимости — в `tools/localls.spec`.
Обычная локальная подготовка: установите Node.js/npm, rpm-build и desktop-библиотеки
средствами Fedora; нужен интернет для npm и загрузки Electron.

```sh
cd linux
npm ci
npm test
npm run build:rpm
```

Результат: `artifacts/LocalLS-0.9.5-Fedora-x86_64.rpm`.
Скрипт использует установленный официальный Electron из node_modules/electron/dist.
Для другого доверенного каталога Electron задайте LOCALLS_ELECTRON_DIST.
Проверка установленного RPM в тестовом контейнере:

```sh
LOCALLS_TEST_EXECUTABLE=/opt/localls/localls bash tools/run-ui-fedora.sh
```

UI-тест требует Playwright, Xvfb, Openbox и dbus-run-session. Флаг --no-sandbox
используется только тестовым запуском в контейнере; RPM launcher его не содержит.
Физические GNOME/Wayland, KDE, polkit, Wi-Fi и VPN-аккаунт в этой среде недоступны.
Мастер DNF не предназначен для Silverblue/Kinoite/Atomic; другие версии Fedora
пока не проверены. Вход по приватному SSH-ключу и рекурсивная передача папок не
реализованы. Подробности фактически выполненных проверок — в BUILD_REPORT.md.

## Безопасность обновления

Добавлены создание/импорт SSH-ключа, установка публичного ключа с проверкой нового входа и строгий режим publickey без парольного fallback. Управляющий агент теперь использует HTTPS с явной проверкой сертификата. Парольный вход самого сервера автоматически не выключается. См. [руководство безопасности](../SECURITY_GUIDE_RU.txt) и [English security guide](../SECURITY_GUIDE_EN.txt).
