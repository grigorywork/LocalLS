# LocalLS для Fedora

Клиент и встроенный SSH/SFTP-сервер. Автор — **MSS9LN**. Версия **1.41**.

1. Установи RPM: `sudo dnf install ./LocalLS-1.41.0-Fedora-x86_64.rpm`.
2. На сервере выбери папку, включи LocalLS и покажи QR-код.
3. На другом устройстве считай QR, сверь код и подтверди устройство на сервере.
4. Передавай файлы через «Файлы». В «Очереди» — время, повтор, отмена и очистка.

Системный OpenSSH не меняется. Закрытие окна сворачивает LocalLS; полный выход — в настройках. Для сохранения ключей нужна разблокированная системная связка ключей. Если входящие подключения блокируются, разреши выбранный порт в брандмауэре доверенной сети.

Светлый фон, матовые панели и светлая обводка переключаются отдельно. Матовые панели оформляются внутри окна; размытие рабочего стола GNOME/KDE не обещается.

[Проверки сборки](docs/BUILD_REPORT_1.41_20261102.md). RPM не подписан ключом издателя.

Сборка: `npm ci`, `npm test`, `npm run build:rpm` в Fedora x86_64. Зависимости среды — в `tools/Fedora.Dockerfile`; старые инструменты системного SSH используются только историческими проверками и в RPM не входят.
