# LocalLS для Debian

Debian 13, amd64. Клиент и встроенный сервер с QR-кодом. Автор — **MSS9LN**.

1. Скачай DEB и установи: `sudo apt install ./LocalLS-1.42.0-Debian13-amd64.deb`.
2. На сервере выбери папку и включи LocalLS. Покажи QR-код.
3. На другом устройстве считай QR, сверь код и разреши доступ на сервере.
4. Передавай через «Файлы». В «Очереди» — время, отмена и очистка.

Нужна разблокированная системная связка ключей. OpenSSH, брандмауэр и автозапуск не меняются. Полный выход — в настройках.

Пакет пока без подписи издателя. Debian 12, Ubuntu и другие системы отдельно не проверены.

Сборка: `node tools/build-deb.cjs /путь/к/проверенному/app.asar /новая/папка`. Скрипт проверяет совпадение общих исходников и версии с ASAR; исходный RPM не меняется. Среда Debian — `tools/Debian.Dockerfile`.
