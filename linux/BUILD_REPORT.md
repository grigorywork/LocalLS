## Реальная сборка и установка

Сборка выполнена в Fedora обычным пользователем:

```sh
LOCALLS_ELECTRON_DIST=/path/to/official/electron/dist bash tools/build-rpm.sh
```

Скрипт вызывает electron-builder --linux dir --x64, затем **rpmbuild -bb**.
Обе стадии завершились с exit 0; rpmbuild вывел Wrote: localls-0.1.0-1.x86_64.rpm.
Полученный RPM скопирован в artifacts с указанным выше именем и проверен rpm -K.
Выполнена настоящая установка пакета через DNF; финальный пересобранный пакет
повторно установлен через `rpm -Uvh --replacepkgs`. Обе установки завершились с exit 0.
Установка LocalLS не запускает sshd, не меняет автозапуск и не открывает firewall.

## Изменения и исправления аудита

1. Выделен независимый linux/ с Linux-упаковкой вместо NSIS/Windows-команд.
2. В Fedora зависимости libXss/xorg-x11-utils оказались неподходящими именами;
   установлены реальные libXScrnSaver и необходимые доступные пакеты.
3. Buildx пытался записать кэш в read-only домашний каталог; кэш перенесён
   в отдельный разрешённый каталог без подмены HOME/DOCKER_CONFIG.
4. Добавлен мастер управления существующей sshd.service: установка OpenSSH,
   start/stop/restart, отдельные enable/disable, стандартное правило SSH:22
   в runtime/permanent firewalld default zone. sshd_config и ключи сохраняются.
5. Привилегированные действия идут только через установленный root-owned помощник,
   Python -I и pkexec, с фиксированным whitelist и без произвольного shell-кода.
6. Проверка текущей учётной записи выполняет настоящий SSH/SFTP-вход на loopback;
   экспорт профиля разрешён только после успеха. Пароль проверки очищается.
7. На GNOME отсутствие трея не должно прятать единственное окно:
   сворачивание/закрытие минимизирует окно; отдельный пункт завершает приложение.
8. Windows-only ограничения имён скачиваемых файлов убраны на Linux;
   защита от путей, NUL и обхода папки сохранена.
9. Linux Tailscale использует штатный CLI/системное подтверждение. Официальный
   URL входа проверяется; ожидание первоначального up ограничено 30 секундами.
10. Системные окна GNOME/KDE используются для Wi-Fi и пароля учётной записи.
11. Backend safeStorage basic_text не допускается: без системного шифрования
    пароль хранится только в памяти, сохранение отключено.
12. Первый UI-тест без оконного менеджера не подтверждал minimized state;
    добавлен Openbox и ожидание фактического состояния окна.
13. UI-передача 8 MiB превысила прежнее тестовое ожидание 30 секунд;
    увеличено ожидание до 120 секунд для реальной медленной тестовой SFTP-службы.
    Финальный тест с проверкой байтового равенства успешно завершился.
14. Исправлено ожидание fixture-имени: мастер использует текущую учётную запись.

## Ограничения и невыполненные проверки

Контейнер не содержит полноценного systemd PID 1 и физического рабочего стола.
Поэтому end-to-end на настоящем Fedora-компьютере ещё нужны:
polkit password prompt, DNF через мастер, start/stop/restart systemd,
firewalld выбранного реального интерфейса, GNOME/Wayland/KDE,
разблокированная связка ключей, реальная смена Wi-Fi и Tailscale с аккаунтом.
Административный помощник проверен на whitelist/владение, но успешные действия
systemd/firewall через графический polkit в этом отчёте не заявляются.

Дополнительный тест изолированного системного OpenSSH с PAM-учётной записью
не завершён: первый запуск дал ошибку тестовой среды; следующая административная
команда была отклонена средой с сообщением Rejected(denied).
Это не засчитано как успешная проверка системного OpenSSH. Успешные SSH/SFTP-тесты
выше используют реальный сетевой SSH/SFTP fixture на ssh2, а не штатный sshd.

Тестовый контейнер также не имеет FUSE/PipeWire и полноценного desktop portal;
предупреждения этих служб не прервали успешный UI-тест. --no-sandbox использован
только для ограниченного тестового контейнера; production renderer sandbox=true.

Другая Fedora-версия и Atomic/Silverblue не проверены; мастер DNF для Atomic
не предназначен. Нет входа по приватному SSH-ключу и рекурсивной передачи папок.
Стандартная кнопка firewall относится к SSH:22 в default zone, не меняет custom port.
Старый независимый удалённый агент требует своей установки/токена;
он не нужен локальному мастеру Fedora и не создаётся им.
Подпись RPM издателем ещё не настроена.

Публичная публикация и скачивание дополнительно отражаются в
`docs/FEDORA_PUBLICATION_REPORT.md`; успешный локальный тест не заменяет проверку ссылки.
