# Аудит Fedora 0.1.0

Готовый RPM проверен в Fedora 44 x86_64: metadata, digest, установка, rpm -V,
ELF, shared libraries, desktop entry, владельцы файлов и соответствие app.asar исходникам.
SSH/SFTP и установленный интерфейс прошли реальные сетевые/файловые тесты.
Обнаруженные проблемы упаковки, Linux-имён файлов и тестового окружения исправлены.

Администрирование ограничено существующей sshd.service и фиксированными действиями
root-owned помощника через Python -I/pkexec. Конфигурация, host keys, пароли и
механизмы автозапуска не заменяются; приложение не стартует сервер при установке.
Секреты не попадают в профили или plaintext persistence; unsafe keyring отключает
сохранение. Host key проверяется до отправки пароля. Renderer sandbox сохранён.

Факты и ограничения проверок перечислены в BUILD_REPORT.md.
Полноценные polkit/systemd/firewall/GNOME/Wayland/Wi-Fi/VPN нужны на физической Fedora.
Восемь тестов и UI smoke не считаются проверкой этих недоступных возможностей.
Обновлённый npm audit: 0 известных уязвимостей на момент проверки.
