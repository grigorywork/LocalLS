## Что изменилось

- Генерация RSA 3072 и импорт приватного SSH-ключа с парольной фразой.
- Строгий publickey-вход без попытки использовать пароль при ошибке ключа.
- Установка публичного ключа сохраняет старые authorized_keys и их ограничения;
  разрешения .ssh/authorized_keys — 700/600. Новый ключ проверяется реальным входом.
- Только после успеха клиент переключается на ключ и удаляет сохранённый пароль.
- Приватные ключи не передаются в публичный профиль или ответы интерфейсу.
- Агент управления использует HTTPS с точным pin сертификата; до его проверки токен
  не отправляется. HTTP-совместимость выключена по умолчанию и требует подтверждения.
- Смена способа входа закрывает прежнее соединение. Операции с ключом защищены от
  параллельной смены настроек во время установки/импорта.

Парольный вход самого сервера, sshd_config, порт и механизмы запуска не меняются
автоматически. Существующая рабочая схема Termux сохраняется. Для запрета серверных
паролей нужны проверенные ключи на всех устройствах и резервный доступ.

## Исправленные проблемы

Предыдущие клиенты использовали только пароль; управляющий HTTP-канал передавал
токен без TLS. Добавлены строгие ключи и проверяемый HTTPS. Исправлены риск потери
существующих строк authorized_keys, добавление того же ключа без прежних ограничений,
сохранение старого соединения после смены режима и гонка установки со сменой профиля.
Ошибки ключей/сертификатов показываются без исходных сообщений с секретами.

## Ограничения

SSH/SFTP проверен на изолированных Node/Paramiko-серверах; это не проверка
пользовательского Termux-сервера. Физические Windows 10/11, телефоны, GNOME/Wayland,
изменение системного Wi-Fi, внешний Tailscale-аккаунт и WAN/IPv6 роутера не проверены.
OS keyring/DPAPI в реальной Windows и постоянное хранение в пользовательской Fedora
требуют проверки на целевой ОС; без системного шифрования ключи остаются в памяти.
Графическая проверка Windows-проекта выполнялась через Linux Electron; RPM GUI
запускался из установленного пакета в Fedora 44 X11/Openbox. --no-sandbox применён
только внутри изолированных UI-тестов, не в поставляемом ярлыке.
