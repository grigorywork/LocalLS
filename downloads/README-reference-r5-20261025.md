# LocalLS — эталон интерфейса UI-R5

Щит с ключом и орбитой, глаз показа/скрытия, контуры и разделители серверных строк приведены к утверждённым эталонам. Линия заголовка устройств непрерывна, индикаторы в одной колонке, лишние линии последней строки и футера убраны. Проверены пять тем и четыре формы кнопок. Сохранённый выбор темы не переключается. Отметка UI-R5 в диагностике. 382 JVM и19 Python тестов прошли. Прежняя подпись, ключи и настройки сохранены. Android0.11.21/code41. Устанавливать поверх приложения.
