[Скачать APK](../LocalLS-1.38-code60-screen-off-wifi-fix-20261030.apk) · [SHA-256](SHA256SUMS.txt) · [Отчёт](audit.txt)

Служба сервера теперь удерживает Wi-Fi вместе с процессором, пока сервер включён. При остановке блокировки освобождаются. Прежняя подпись, ключи, настройки и оформление сохранены.

469 JVM-тестов, 19 Python, lint и 16 минут реального loopback-простоя с последующей передачей прошли. Физический сон Android/Doze здесь не проверялся; для LocalLS на телефоне-сервере разреши работу без ограничений в настройках батареи.

Windows 1.39 не менялся. Устанавливай APK поверх предыдущего приложения.
