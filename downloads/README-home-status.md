# LocalLS — показатели сервера и основные действия

[Android APK](LocalLS-0.11.21-home-status.apk) · [Windows x64 installer](https://media.githubusercontent.com/media/grigorywork/LocalLS/downloads/localls-home-status-235f0996/downloads/LocalLS-0.9.5-Windows-x64-home-status-Setup.exe) · [Скриншоты](interface-home-status-20261023/README.md) · [Отчёт](REPORT-home-status-20261023.md)

На главном экране принимающего устройства отображаются заряд батареи и свободное место телефона-сервера. Оба устройства должны получить эту сборку: сервер передаёт показатели внутри прежнего защищённого SSH-соединения, только после входа по разрешённому ключу. Оболочка и парольный вход не включаются.

На Android четыре основных действия: проверить сервер, файлы, очередь, меню. Второстепенные действия перенесены в меню; оба графика и графика сохранены. Повторные переходы в настройках сервера убраны, включение/остановка объединены. На ПК убраны повторные быстрые команды; функции остаются в своих разделах.

Android 0.11.21 / code41, ПК0.9.5, прежняя подпись. 330 JVM +19 Python, Node14+18 и GUI-проверки прошли. Физические телефоны и Windows runtime не проверялись. Функциональный исходный код остаётся в рабочей копии и закрытом архиве; артефактный commit содержит бинарники, снимки и отчёт. Ветка выпуска и опубликованный release сохранены.
