# LocalLS — кнопки проверки и значки типов файлов

Android0.11.21 / versionCode41, package com.bitpoint.homeservercontrol. Прежний сертификат SHA256 a2230c3032135def93cd5e8224ca3e26ad8e98f294b5e372a33b1e468caa221a.

На главной кнопка проверки отображается только значком, как уточнил пользователь. Назначение сохранено в accessibility contentDescription. Значок без подписи центрируется по высоте кнопки. В «Подключении» добавлена отдельная кнопка «Проверить SSH» с видимым результатом. Обе вызывают существующую проверку по ключу и блокируются на время запроса; повторные нажатия во время проверки блокируются. Смена параметров убирает старый результат, отмена проверки сбрасывает надпись ожидания. Pin и запрет подключения при смене ключа сохранены.

Единые офлайн-значки Lucide применены в локальном/серверном файловом менеджере, текущей/последних передачах, очереди и старом окне принятых файлов. Категории: изображения, документы, PDF, CAD/DWG/DXF/DWT, архивы, видео, аудио, папки и неизвестные файлы. PDF и CAD снабжены метками расширения. Тип определяется последним расширением, без чтения содержимого и сетевых запросов. Сохранены галочки, сортировка, удержание для просмотра и меню действий. На тесном экране значки истории уменьшаются, чтобы не обрезаться.
