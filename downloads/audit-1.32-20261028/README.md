# LocalLS 1.32 — итог двухчасового окна аудита

[Скачать APK](../LocalLS-1.32-code54-audit-20261028.apk) · [SHA256](../LocalLS-1.32-code54-audit-20261028.apk.sha256)

Исправлены две воспроизведённые ошибки поиска сервера:

1. При нескольких найденных адресах Android AlertDialog показывал сообщение и не присоединял список к окну. Теперь виден список с заголовком «Выбери SSH-сервер». Выбор меняет черновик; сохранение адреса и подтверждение доверия остаются отдельными действиями.
2. Поиск ошибочно ожидал весь префикс `SSH-` в одном TCP-read. Ответ «S», затем «SH-…» терялся. Теперь четыре байта собираются с единым прежним пределом 350 мс; медленная побайтовая выдача не продлевает ожидание.

Добавлены пять регрессий: видимость/выбор/отмена/подтверждение в нативном диалоге телефона и планшета, темы/стекло/48dp, реальная фрагментация TCP и ограниченный общий срок чтения. До исправления подтверждены RED, после — GREEN. Все прежние **450 test IDs** сохранены и не редактировались.

## Фактические проверки

Финальный полный прогон после окончания окна: **455 JVM + 19 Python**, без ошибок, пропусков и необработанных исключений. Проверены все **102** ссылки функциональной матрицы, lintDebug/lintRelease, release/debug/androidTest-сборки: **BUILD SUCCESSFUL**. Изменения Android: два production-класса, версия и два новых тест-класса. Автор **MSS9LN**, package `com.bitpoint.homeservercontrol`, версия **1.32/code54**.

Всего автоматических успешных стадий: **31**, в том числе 4 полных. Целевые сценарии SSH/SFTP, QR/профили, очередь/папки и отрисовка повторялись. До начала новой Windows-работы также повторялись существующие Windows/Fedora Node-тесты на Linux; это не физический Windows/Fedora runtime. Нативные снимки/проверки выполнялись Robolectric, сетевые — на изолированном loopback SSH/SFTP. Физические телефоны и планшеты не подключались; instrumentation APK собран, на устройства не устанавливался.

## Время и паузы

Окно: **28.10.2026 13:25–15:25 МСК** (10:25–12:25 UTC). Оно не продлевалось. Автоматические стадии внутри окна заняли примерно **88.6 мин**, отдельные ручные RED/GREEN-прогоны — **4.5 мин**. Это не утверждение о двух часах непрерывного тестирования.

Были штатные паузы: 14:40–14:47 МСК для воспроизведения и исправлений; с 15:00 МСК — для отдельно порученной пользователем Windows-версии с клиентом и сервером. Остановок среды по heartbeat не обнаружено. После 15:25 МСК выполнен отдельный финальный полный прогон; он завершился **15:38:18 МСК**. Его время не прибавлено к двухчасовому окну. Windows-разработка продолжается отдельно; её незавершённые функции в Android APK не входят. Fedora пока не портируется.
