# LocalLS — главная, удержание для просмотра, Поделиться и форма кнопок

[Скачать APK](LocalLS-0.11.21-dashboard-share-preview.apk) · [8 снимков интерфейса](interface-dashboard-final-20261023/README.md) · [Полный отчёт](REPORT-dashboard-share-preview-20261023.md)

Установи APK поверх текущего приложения на принимающий телефон/планшет и телефон-сервер, без удаления. Android0.11.21/code41 и прежняя подпись сохранены. Новый сервер добавляет статус зарядки; старый v1-протокол сохранён для совместимости ПК.

Главная адаптируется под планшет и телефон, сохраняет оба графика и показывает память/батарею сервера, текущую передачу и три последних результата. Внешняя форма меняется у всей кнопки, вместо рамки вокруг маленького значка. Пункты круглой/скруглённой/прямоугольной формы находятся в «Меню → Оформление → Форма кнопок».

Удержание файла открывает временный просмотр; отпускание закрывает его и останавливает воспроизведение. Поддерживаются фото, видео/аудио, первая страница PDF и текст; действия с файлом находятся в ⋮. Большие удалённые видео сначала скачиваются обычной командой, затем локальное видео воспроизводится без копирования целого файла.

Для быстрой отправки включи «Настройки → Поделиться → LocalLS: отправлять сразу на сервер» и нажми «Сохранить». После этого выбирай LocalLS в системном меню «Поделиться» другого приложения. По умолчанию требуется подтверждение. На встроенном телефоне-сервере завершённые файлы автоматически сохраняются в «Загрузки / LocalLS» или ранее выбранную папку; настройки папки не переписываются. Подготовка делает приватную копию, после её завершения очередь работает независимо от временного разрешения исходного приложения. Если сервер недоступен, задание сохраняется для продолжения из очереди.
