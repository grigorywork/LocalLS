# LocalLS: Windows 1.35 и Android 1.37

Автор — MSS9LN. Проверено 29 октября 2026 года.

- Android: «Подключение → Сканировать QR → Открыть QR-код из файла». PNG и фото читаются без камеры. Сохраняются проверка ключа и подтверждение доступа. QR действует 10 минут; подтверждённая привязка бессрочная.
- Windows: «Подключение → Открыть QR-код». Исправлено чтение прозрачного PNG.
- Светлый фон и стекло на Windows применяются и сохраняются сразу. Файловый менеджер сохраняет режим подключения после смены оформления.
- Исправлены высота QR-кнопки на низком экране Android и перенос кнопок в узком окне Windows.
- Windows: установщик 104.00 → 95.76 МБ; установленная программа 340.24 → 312.88 МБ. Сохранены кодеки, лицензии и обычный графический резервный путь. При обновлении удаляются только три известных устаревших файла программы.

## Реальные проверки

Android: полный прогон 466 JVM, без ошибок/пропусков; все 462 прежних ID сохранены; 4 новые проверки импорта PNG. Дополнительно 17 целевых JVM; 19 Python; 102 ссылки матрицы функций. Lint debug/release: 0 errors/fatal/UnusedResources, по 157 предупреждений. Исходники зафиксированы во время Gradle; BUILD SUCCESSFUL. Сертификат прежний, ZIP alignment и совместимость обновления с 1.36 проверены. Новый считыватель и кнопка присутствуют в DEX проверенного APK.

Windows: 57 Node-тестов, дополнительная перепроверка 2 тестов упаковки, 6 сценариев интерфейса исходников и 4 сценария финального app.asar. 32 сочетания темы/фона/стекла, перезапуск, PNG/JPEG, реальный SSH/SFTP с независимым разрешением владельца, папки, отмена и защита от устаревшего подключения. Новый настоящий NSIS Unicode; версии PE и автора проверены; извлечённые EXE и app.asar совпадают с проверенным пакетом. SHA-256 указан рядом. Исходная release-ветка/тег и прежние артефакты сохранены.

## Ограничения

Android проверялся через native Robolectric и локальные сетевые стенды, без физических устройств. Интерфейс финального app.asar запускался в Linux Electron. Физический Windows 11/DWM, установка и удаление на Windows здесь не запускались. Системное матовое стекло предназначено для Windows 11 22H2+; на других системах доступны матовые панели. Windows EXE без Authenticode; это не заменяется SHA-256. APK подписан прежним сертификатом `a2230c3032135def93cd5e8224ca3e26ad8e98f294b5e372a33b1e468caa221a`.
