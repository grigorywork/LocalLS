# LocalLS — проверка атак и защита сервера

Исправлены два пути отказа в обслуживании: удержание множества файловых handles и непроверенная длина/очередь SFTP-пакетов. Также отключены устаревшие подписи RSA/SHA-1 без смены сохранённого RSA-ключа. Проверки ключей, QR и границ папки сохранены. APK0.11.21/code41 подписан прежним сертификатом. Устанавливать поверх без удаления данных. Полный прогон и подробные результаты — [в отчёте](REPORT-server-security-20261024.md). Это локальная проверка перечисленных сценариев, не проверка физического телефона и не гарантия от всех возможных атак.
