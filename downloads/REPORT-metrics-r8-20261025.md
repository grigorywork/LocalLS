# LocalLS UI-R8 — компактные карточки, вариант 2

Два блока на главной принимающего устройства переделаны по выбранному второму макету: один значок в мягком квадрате, короткий заголовок, значение справа, подпись и тонкий индикатор. Карточки используют выбранную тему приложения; автоматической смены темы нет. Макет сервера, QR-вход и доступ по ключам сохранены.

## Раскладка

Каждый элемент получает отдельную измеренную область: цифры, подписи и индикатор больше не пересекаются. Обе карточки используют одинаковую компоновку верхней строки. При недостатке ширины заголовок располагается над числом внутри строки, индикаторы остаются на одном уровне. На небольшом экране вспомогательные подписи скрываются по прежнему правилу, полный показатель остаётся доступен для чтения экрана.

Индикатор памяти показывает занятое место, батареи — заряд. Для данных со снимка: 73,3 ГБ свободно из 225,8 ГБ; занято 152,5 ГБ (68%); батарея 39%. Ранее целочисленная полоса могла показывать67%, а округлённая подпись68%; теперь округление одинаковое. При отсутствии показателя заполнение сбрасывается; значения не выдумываются. Проверены0%,100%, неизвестный заряд и накопитель1024ГБ. После поворота зарезервированная ширина для100% сохраняется.

Проверена геометрия и полная видимость текста на320×568,360×640,411×890,890×411 и1280×800, при160/320dpi, шрифте1×/2× и пяти темах. Два новых регрессионных теста проверяют все видимые прямоугольники карточек на пересечения/выход за контур, отсутствие обрезки и многоточия, направление и значения индикаторов, сброс устаревших данных. Прежние проверки центрирования значения на самом сервере сохранены; для выбранной новой клиентской компоновки проверяется выравнивание справа и отсутствие пересечения со значком. Минимальная высота графика рассчитывается по фактической высоте его заголовка и текста; проверка полного48dp-графика сохранена в прежнем DashboardRestoreTest. Графики, три строки истории и четыре основных действия сохранены.
