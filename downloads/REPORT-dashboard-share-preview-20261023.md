# LocalLS — адаптивная главная, форма кнопок, просмотр удержанием и отправка из других приложений

Android 0.11.21 / versionCode 41, package com.bitpoint.homeservercontrol. Пересборка прежней версии с прежней подписью; новый release/tag/версия не создавались.

## Главная

На планшете левая колонка состояния/памяти/батареи, справа крупные графики SFTP и отклика SSH, текущая передача и три последних результата; снизу четыре основных действия. На телефоне карточки памяти и батареи компактнее и стоят рядом, под ними оба графика, передача и три последние строки. Главная без ScrollView и прокрутки. В очень низком горизонтальном окне остаётся компактный обзор; подробности доступны в очереди. При большом системном шрифте тесный экран уплотняется до нормального размера шрифта главной, без уменьшения целевых областей основных кнопок ниже 48dp. Формы, цвета пяти тем, разделение роли телефона-сервера и клиента сохранены.

Память и батарея относятся к серверу: свободный/общий объём и заполнение, заряд, статус зарядки, uptime и давность снимка. Показатель свободного места относится к тому SFTP-раздачи; ранее выбранная папка последующего автоматического сохранения не меняется. Новый read-only subsystem localls-status-v2 добавляет статус зарядки; прежний v1 сохранён для старых клиентов ПК/Android, новый клиент умеет fallback на v1. Новый порт/HTTP/командная оболочка/парольный вход не добавлялись. Pin и доказательство приватного ключа обязательны. Неизвестный статус зарядки остаётся неизвестным.

Процент, имя файла, скорость и ETA берутся из текущей передачи; последние результаты читаются из сохранённого журнала. При отсутствии заданий показывается пустое состояние. Нажатие текущей передачи предлагает остановку очереди с подтверждением; нажатие истории открывает очередь. Демонстрационные цифры находятся только в тестах/скриншотах, не в рабочей телеметрии.

## Внешняя форма кнопок

«Меню → Оформление → Форма кнопок»: без рамки, круглая (овальная для широких кнопок), скруглённая, прямоугольная. Меняется фон/окантовка всей кнопки. Обёртка вокруг маленького функционального значка больше не используется. Форму получают также динамически создаваемые кнопки «⋮» в строках файлов. Сохранённый индекс настройки не сбрасывается. Прямоугольные целевые области нажатия остаются удобными независимо от рисунка контура; системные диалоги Android сохраняют системный вид.

## Просмотр удержанием

Удержание файла открывает временный просмотр; отпускание/отмена жеста/уход с экрана сразу закрывает его и останавливает VideoView. Фото, видео, аудио, первая страница PDF и текст открываются внутри приложения. HTML отображается как текст, код не выполняется. Остальные документы, включая неподдерживаемые офисные форматы, получают понятное сообщение. Выделение галочкой и обычное открытие папок сохранены; переименование, удаление и сведения находятся в «⋮». Для папки прежнее долгое нажатие открывает действия.

Локальные видео/аудио открываются по уже разрешённому URI без копирования целого файла. Для удалённого файла нужен предварительный read-only SFTP-запрос. Временная копия ограничена 128 МБ; большие удалённые видео сначала следует скачать обычной командой, после чего локальное видео воспроизводится без этой копии. Тип файла определяется по расширению имени, включая кириллицу; URL-парсер для имён не применяется. Фото декодируются с ограничением размеров, PDF — первая страница, текст — первые 128 КБ. Кэш приватный, удаляется после использования; поздние callbacks не открывают окно снова. Существующий FLAG_SECURE не сбрасывается; на время просмотра добавляется защита снимка экрана.

## Поделиться → LocalLS

Настройки → «Поделиться → LocalLS: отправлять сразу на сервер» → Сохранить. По умолчанию выключено: входящее вложение открывает подтверждение. После включения один выбор LocalLS в системном меню «Поделиться» начинает подготовку и отправку без второго подтверждения. Поддерживаются 1–64 URI файлов, неизменённый сохранённый endpoint, pin и ключ. Повторный QR не нужен. При отсутствии подтверждённого сохранённого доступа отправка блокируется.

Сначала приложение сохраняет свои копии вложений в приватную outbox; после подготовки создаётся задание прежней долговечной очереди и запускается прежняя foreground-служба. Поэтому уже поставленные в очередь файлы не зависят от временного разрешения Telegram/другого источника и переживают перезапуск. До окончания подготовки окно должно оставаться открытым; закрытие прерывает незавершённую подготовку. При недоступном сервере задание и копии остаются для продолжения из очереди. После завершения копии удаляются. При совпадении имён сохраняются обе копии; старые файлы не заменяются.

Файл отправляется в корень привязанной раздачи. Встроенный телефон-сервер автоматически сохраняет завершённые передачи в «Загрузки / LocalLS» либо ранее выбранную папку приёма. Настройки этой папки не переписываются. Для обычного стороннего OpenSSH/SFTP-сервера используется его корень/домашняя папка, автоматическое Android-сохранение там отсутствует.
