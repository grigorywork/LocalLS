# LocalLS — главная по двум утверждённым ориентирам

Телефон вертикально — компактные карточки рядом, оба графика и три последних файла. Планшет/горизонтальный телефон — две колонки. Общая нижняя панель, заливка графиков, округлые полосы, отдельный процент передачи. Без прокрутки; особо низкие окна используют компактный обзор.

Android0.11.21/code41, прежняя подпись и настройки сохранены. Установка поверх прежнего приложения без удаления. 341JVM+19Python прошли, прежние341 тестов сохранены. Физические устройства не проверялись. Подробности и пределы — в отчёте.

Публикация только APK/снимков/отчёта. Текущие функциональные исходники остаются в рабочей копии и закрытом архиве; release-ветка и опубликованные release assets не изменяются.
