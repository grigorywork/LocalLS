LocalLS Windows 1.40 — MSS9LN

Добавлено по запросу:
- «Отменить все» останавливает текущую передачу и все ожидающие задания, включая не отображаемые в коротком списке.
- «Очистить список» после подтверждения отменяет незавершённые задания и удаляет всю очередь/историю. Исходные и завершённые файлы на устройствах сохраняются. Пустой журнал записывается до удаления записей из памяти; при ошибке диска записи не забываются.
- Быстрый просмотр фото, видео и PDF на сервере/ПК: удерживай мышь на файле; отпусти, чтобы закрыть. Обычный щелчок выбирает файл. Кнопка «Просмотр» открывает постоянное окно, закрываемое Esc или крестиком. Используется встроенный просмотрщик Chromium, без новых библиотек.

Просмотр: отдельное SSH-соединение с прежним строгим pin/key/password-профилем, без ослабления доверия; его закрытие не обрывает основную очередь. Лимит128МиБ как на Android, для больших файлов сначала скачивание. Временный кэш удаляется при закрытии/обрыве, URL отзывается; старый ответ не подменяет новый просмотр. HTML/SVG/EXE, ссылки и произвольные локальные пути не открываются. Внешние переходы запрещены прежним обработчиком/политикой приложения; Node в renderer выключен, sandbox/contextIsolation сохранены. Оформление использует существующие темы, светлый фон, стекло и обводку.

Проверки:
- 84 свежих Node-теста,0ошибок/пропусков;76 прежних тестов сохранены,8 новых функциональных регрессий. В том числе отмена/очистка1000заданий посреди реальной передачи, ошибки записи журнала, HTTP Range/HEAD и отзыв URL, слишком большие файлы/ссылки/активные форматы, поздние ответы, потеря сети и молчащий сервер просмотра без потери основного SFTP.
- 5 производственных loopback SSH/SFTP проверок,64МиБ в обе стороны с совпадением SHA-256; Unicode, нулевой файл, пустая папка, отмена, отключение и повторный вход с прежним ключом.
- 6 сценариев точного финального app.asar в Electron: прежние client/QR/server/stale-connect/invalid-save и новый queue-preview. Настоящие PNG-пиксели, декодирование/воспроизведение WebM, PDF-страница через встроенный pdf-viewer, удержание/отпускание и постоянный просмотр, native подтверждения отмены/очистки, очистка250+записей в журнале, исходники файлов сохранены, кэш пуст. GUI-проверки использовали локальные тестовые данные; не заявляется прогон на физической Windows.
- Отдельно текущий Node-клиент -> Java серверный код Android: чтение тестовых файлов через отдельные pinned SSH-соединения, основной файловый менеджер остаётся живым, затем1МиБ отправки и повторный вход без перезапуска сервера. Это протокольный loopback; декодирование медиа проверено отдельно в GUI.
- Реальные PE версии1.40.0/MSS9LN, NSIS Unicode/x64 payload, исходники/asar, зависимости, лицензии и резервный графический путь проверены; из установщика извлечены EXE/app.asar и сверены по SHA-256. BUILD SUCCESSFUL.

Windows EXE БЕЗ Authenticode: доверенный сертификат/сервис всё ещё не оформлен; SmartScreen может предупреждать о неизвестном издателе. Android1.38/code60 не менялся и не пересобирался; прошлые469Android-тестов не выдаются за новый прогон. Нативные Windows DWM/DPAPI/установка, физический Android/Wi-Fi/Doze здесь не проверялись. Стенд: Linux Node/Electron и JVM/loopback.
